# Probabilidade e Estatística

Este repositório contém os materiais (resumos expandidos, scripts em R, gráficos e slides) do trabalho de Probabilidade e Estatística.

## Resumo

O mercado automotivo contemporâneo é caracterizado por uma vasta diversidade de modelos, tecnologias e faixas de preço. A decisão de compra de um consumidor, assim como a estratégia de precificação de um fabricante, é influenciada por uma complexa interação de fatores, desde a potência do motor até o prestígio da marca. Este estudo utiliza técnicas de análise exploratória de dados para quantificar e compreender as principais relações que governam este cenário, focando em como os atributos técnicos de um veículo se refletem em seu valor de mercado e em sua performance.

A base para esta investigação é um conjunto de dados obtido na plataforma Kaggle, intitulado [Cars Dataset (2025)](https://www.kaggle.com/datasets/abdulmalik1518/cars-datasets-2025) . Este dataset consolida as especificações de centenas de veículos, fornecendo um campo rico para a aplicação de métodos estatísticos.

O objetivo central é responder a perguntas-chave do setor: 
- Qual é o real impacto das especificações do carro, como tipo do motor e cavalos de potência, no preço final de um veículo?
- Qual o preço médio de um carro por marca?
- Qual a relação entre velocidade máxima e desempenho (tempo para chegar de 0 a 100 km/h)?

Adicionalmente, busca-se explorar o trade-off entre utilidade e esportividade, analisando como atributos familiares, como o número de assentos, se correlacionam com indicadores de alto desempenho. Ao final, este trabalho visa oferecer um panorama claro, baseado em evidências, dos fatores que mais contribuem para a configuração do mercado automotivo, fornecendo insights sobre a estrutura de preços e as tendências de engenharia do setor.
